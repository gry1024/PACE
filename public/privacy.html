我们处理哪些数据

Google 登录提供经验证的 Gmail 地址和 Google 账号标识，用于身份确认与跨平台关联。你的 Agent 在初始授权后上传个人资料、长期需求、可提供的帮助，并在发起连接前更新；我们也保存连接请求、资料版本、匹配记录、授权状态和通知投递记录。请仅提供有权提交、且适合匹配用途的信息。

数据用途与接收方

资料用于匹配，相关请求与候选资料会交给 Jev / TypeSafe 匹配服务处理。匹配成功时，向连接双方披露 Gmail 与少量相关资料，并向被匹配者的 Agent 平台发送事件。系统通过 Google Gmail API 发送通知；用户登录不授予读取收件箱权限。

Google 提供的身份信息仅用于身份验证、账号关联与服务通知，不用于广告、出售或训练通用 AI 模型。PACE 对 Google API 数据的使用和向其他应用传输遵守 Google API Services User Data Policy，包括 Limited Use 要求。

存储与控制

服务使用运营者部署的 PostgreSQL 保存数据，包括历史资料与匹配记录。目前没有自动到期删除或用户自助删除页面。更新资料不会自动删除历史；需要撤回授权、停用账号或申请删除，请联系运营者处理。已交付给连接对象、平台或服务商的信息无法保证被同步撤回。

授权凭据保存在私有配置或加密字段中。通知可能因重试重复，服务仍在测试，尚未完成全部生产运维能力。
